# 🚀 算法精进笔记：动态规划 (DP) 基石与极致空间压缩

> **💡 核心心法 (DP 五部曲)**：
> 1. **定义状态**：明确 `dp[i]` 或 `dp[i][j]` 代表的物理意义。
> 2. **状态转移方程**：找到当下状态与历史状态的历史渊源（核心推导）。
> 3. **初始化**：处理好起点边界，防止越界。
> 4. **遍历顺序**：通常从小到大，确保计算当前状态时，依赖的历史状态已计算完毕。
> 5. **返回结果**：根据题意返回 `dp` 数组中的某个特定值。
>
> **🌟 进阶架构思维**：大厂面试极度看重**“状态压缩（滚动变量）”**。如果当前状态只依赖前一个或前两个状态，坚决废弃 $O(N)$ 数组，改用常数个变量 $O(1)$ 滚动覆盖！

## 🟢 一、 力扣 70. 爬楼梯 (DP 思想启蒙与斐波那契)

### 📝 解题思路 (一维递推)
爬到第 `i` 层，只有两种可能：从 `i-1` 层爬一步上来，或者从 `i-2` 层爬两步上来。
**状态转移方程**：`dp[i] = dp[i - 1] + dp[i - 2]`。

### 🚀 极客优化 (O(1) 滚动变量)
不需要维护长达 $N$ 的数组。当前台阶的方法数只跟“前一级”和“前两级”有关。我们只需要两个变量 `prev` 和 `cur` 互相交替向前滚动。
*   **工程素养**：坚持使用 `tmp` 变量来完成状态覆盖。这种写法跨语言通用（C++/Java皆可），清晰展现了底层内存更新的原子操作，逻辑严密。

### 💻 核心代码 (Python)
```python
class Solution(object):
    def climbStairs(self, n):
        # 初始化：prev 代表 i-2 层，cur 代表 i-1 层
        prev, cur = 1, 1
        
        for _ in range(2, n + 1):
            tmp = cur               # 1. 暂存旧的 i-1 层数据
            cur = prev + cur        # 2. 计算出新的 i 层数据，覆盖 cur
            prev = tmp              # 3. 原来的 i-1 层退化为 i-2 层，赋给 prev
            
        return cur
```
*   **复杂度**：时间 $O(N)$，空间 $O(1)$。

## 🟡 二、 力扣 118. 杨辉三角 (二维展开与 Python 浅拷贝陷阱)

### 📝 解题思路 (二维状态转移)
杨辉三角的每个数字等于它正上方和左上方的两个数字之和。
**状态转移方程**：`dp[i][j] = dp[i-1][j-1] + dp[i-1][j]`。

### 🚨 极客避坑指南 (Mutable Object 引用陷阱)
如果尝试在一维数组 `cur` 上反复修改，并直接 `res.append(cur)`，会导致结果数组里存的全是**同一个内存地址的指针**！最终输出全变成最后一行的模样。
**破局之法**：在将可变对象存入结果集时，必须使用切片 `cur[:]` 进行**深拷贝（浅拷贝生成新对象）**。

### 💻 核心代码 (Python)
```python
class Solution(object):
    def generate(self, numRows):
        res = []
        for i in range(numRows):
            row =[]
            for j in range(i + 1):
                # 两侧边缘永远是 1
                if j == 0 or j == i:
                    row.append(1)
                else:
                    # 依赖上一行 (res[i-1]) 的历史数据
                    row.append(res[i - 1][j - 1] + res[i - 1][j])
            res.append(row)
        return res
```

### 🧠 进阶降维打击 (逆序遍历消除辅助变量)
如果题目改为**只求第 K 行（力扣 119 题）**，为了将空间压缩至 $O(K)$，我们只需维护一个一维数组。为了防止当前行覆盖掉还需要使用的“旧左上角数据”，**必须从右往左逆序遍历**：
`for j in range(i - 1, 0, -1): cur[j] = cur[j] + cur[j - 1]`
*   **复杂度**：时间 $O(N^2)$，空间 $O(N^2)$（本题需保存全图，若只求最后一行则空间可压缩至 $O(N)$）。

## 🔴 三、 力扣 198. 打家劫舍 (序列状态机与幽灵边界)

### 📝 解题思路 (非此即彼的博弈)
走到第 `i` 个房间，面临人生抉择：
1. **偷**：那 `i-1` 绝对不能偷，最大收益是 `dp[i-2] + nums[i]`。
2. **不偷**：那最大收益沿用 `i-1` 的收益，即 `dp[i-1]`。
**状态转移方程**：`dp[i] = max(dp[i - 2] + nums[i], dp[i - 1])`。

### 🚀 终极绝杀技 (“幽灵状态”初始化)
常规做法需要特判 `len(nums) < 3`，并手动初始化 `prev` 和 `cur`。
**降维打击**：我们在真实的房子前面，假想出两个**“没钱的虚拟空房子”**（收益皆为 0）。将 `prev` 和 `cur` 统统初始化为 `0`，这样不仅消灭了所有越界报错，还省去了所有 `if-else` 分支！

### 💻 核心代码 (Python - 无分支完美版)
```python
class Solution(object):
    def rob(self, nums):
        # 幽灵状态初始化：假装前面有两个没钱的虚拟房间
        # prev: 抢劫前 i-2 个房子的最大收益
        # cur : 抢劫前 i-1 个房子的最大收益
        prev, cur = 0, 0
        
        for num in nums:
            tmp = cur
            # 核心博弈：偷当前房 (prev + num) vs 不偷当前房 (保留旧 cur)
            cur = max(prev + num, cur)
            prev = tmp
            
        return cur
```
*   **复杂度**：时间 $O(N)$，空间 $O(1)$。极致的一遍过，无分支，无冗余。

## 👑 终极领悟：大模型 (LLM) 算法岗的 DP 视野

在面向大模型和自然语言处理（NLP）领域的面试中，这三道题是基石中的基石：
1. **状态机思维（打家劫舍）**：这种“记录多个平行历史状态，每次取最优解向前推进”的思想，正是大模型生成文本时 **Viterbi 解码（维特比算法）** 和 **Beam Search（集束搜索）** 最底层的数学原理。
2. **底层通用与严谨性**：坚持使用 `tmp` 进行状态交替，不仅展现了极强的跨语言代码素养，也高度契合在底层编写 CUDA / C++ 算子时的内存控制规范。
3. **避免浅拷贝陷阱**：杨辉三角中的 `res.append(cur[:])` 陷阱，在深度学习框架（如 PyTorch）中极度常见。理解对象引用，能有效避免训练循环中出现梯度张量（Tensor）被原地覆盖修改（In-place operation）导致的灾难性报错。
