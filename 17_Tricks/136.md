## 用异或(^)位运算解决136只出现一次的数字

### 🔮 第一步：认识“异或”这个魔法符号

在几乎所有编程语言（Python, Java, C++）中，异或的符号都是脱字符 **`^`**。

异或在计算机底层是针对**二进制位（0 和 1）**进行操作的。它的运算口诀只有一句，请牢牢记住：
👉 **“相同为 0，相异为 1”**

我们来看具体的对比：
*   `0 ^ 0 = 0` （两边相同，结果为0）
*   `1 ^ 1 = 0` （两边相同，结果为0）
*   `1 ^ 0 = 1` （两边不同，结果为1）
*   `0 ^ 1 = 1` （两边不同，结果为1）

你可以把异或想象成一个**“消消乐”**游戏：长得一样的遇到一起就同归于尽（变成 0），长得不一样的才能留存下来（变成 1）。

---

### ✨ 第二步：异或的三大数学定律（核心机制）

从“相同为0，相异为1”这个基础口诀，数学家们推导出了异或的三个极其好用的定律。这就是我们解题的终极武器：

**定律一：归零律 (Self-Inverse)**
*   公式：`A ^ A = 0`
*   大白话：**任何数字和它自己异或，结果一定是 0。**
*   解释：因为相同的数字，它们的二进制每一位都完全一模一样。“相同为0”，所以全变成0了。
*   例子：`5 ^ 5 = 0`，`999 ^ 999 = 0`。

**定律二：恒等律 (Identity)**
*   公式：`A ^ 0 = A`
*   大白话：**任何数字和 0 异或，结果还是它自己。**
*   解释：0 的二进制全是 0。根据“相异为1”，原数字里的 1 遇到 0 还是 1，原数字里的 0 遇到 0 还是 0，所以原数字毫发无损。
*   例子：`5 ^ 0 = 5`。

**定律三：交换律与结合律 (Commutative & Associative)**
*   公式：`A ^ B ^ A = A ^ A ^ B = 0 ^ B = B`
*   大白话：**异或运算可以随便打乱顺序，结果不变。**

---

### 💥 第三步：为什么这道题能用异或秒杀？

来看看题目给的特殊条件：
> 给定一个非空整数数组 `nums`，**除了某个元素只出现一次以外，其余每个元素均出现两次**。找出那个只出现了一次的元素。
> 要求：必须实现线性时间复杂度 $O(N)$，且只使用常数级额外空间 $O(1)$。

根据我们刚刚学的“三大定律”，解法呼之欲出：
**我们只需要把数组里所有的数字，全部异或到一起！**

#### 🎲 举个例子推导：
假设给定的数组是：`nums =[4, 1, 2, 1, 2]`。

我们设立一个初始值为 `0` 的变量 `ans`，然后让它和数组里的每个数字一路异或过去：
`ans = 0 ^ 4 ^ 1 ^ 2 ^ 1 ^ 2`

根据**交换律（定律三）**，我们把相同的数字排到一起，长这样：
`ans = 0 ^ (1 ^ 1) ^ (2 ^ 2) ^ 4`

根据**归零律（定律一）**，成对的数字 `1^1` 和 `2^2` 瞬间同归于尽，变成了 0：
`ans = 0 ^ 0 ^ 0 ^ 4`

根据**恒等律（定律二）**，一堆 0 异或 4，结果还是 4：
`ans = 4`

**破案了！** 所有出现两次的数字，在异或的“消消乐”魔法下全都自己抵消变成了 0。最后留下来的，就是那个**唯一出现一次的数字**！

---

### 💻 第四步：写成代码，只有几行！

#### Python 3 基础写法（推荐）：
```python
class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        ans = 0  # 初始值为 0
        for num in nums:
            ans ^= num  # ans = ans ^ num
        return ans
```

#### Python 3 装杯写法（一行流）：
在 Python 中，可以使用 `functools.reduce` 搭配 `operator.xor` 来把整个数组折叠异或。面试时写出这个，直接展示你对 Python 语法的极致掌控：
```python
from functools import reduce
from operator import xor

class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        return reduce(xor, nums)
```

### 📊 复杂度分析
*   **时间复杂度**：$O(N)$。仅仅遍历了数组一次，每次执行一次底层的位运算（极快）。
*   **空间复杂度**：$O(1)$。只用了一个变量 `ans`，没有任何额外的数据结构。完美满足题目那堪称苛刻的要求！
