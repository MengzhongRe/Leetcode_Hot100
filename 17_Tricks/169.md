# 摩尔投票法Boyer-Moore Voting Algorithm 解决169 “多数元素”

下面我将通过**通俗的比喻**、**算法步骤**、**代码实现**三个方面来为你讲解。

---

### 1. 核心思想：通俗的“火拼”比喻

摩尔投票法的核心思想是**“抵消”**或**“同归于尽”**。

题目中有一个重要的前提：**多数元素是指在数组中出现次数 大于 `⌊ n/2 ⌋` 的元素，并且假设数组非空且多数元素一定存在。**

你可以把数组里的数字想象成**不同阵营的士兵**：
* 我们的目标是找出那个**人数超过总人数一半**的阵营。
* 战斗规则是：**两个不同阵营的士兵一旦相遇，就同归于尽（一换一）。**
* 因为多数派的士兵数量比其他所有阵营的士兵数量加起来还要多，所以无论怎么“一换一”，**最后活下来的肯定有多数派阵营的人**。

### 2. 算法步骤

我们需要维护两个变量：
1. `candidate`（候选人）：当前存活的阵营。
2. `count`（票数/士兵数）：当前候选人阵营剩下的士兵数量。初始为 `0`。

**遍历数组中的每一个元素 `num`：**
1. **如果 `count == 0`**：说明当前没有候选人（或者之前的士兵都同归于尽了），我们就把当前元素 `num` 当作新的候选人 `candidate = num`。
2. **如果 `num == candidate`**：遇到自己阵营的士兵，力量增强，票数加一（`count += 1`）。
3. **如果 `num != candidate`**：遇到其他阵营的士兵，进行“同归于尽”，票数减一（`count -= 1`）。

遍历完整个数组后，留在 `candidate` 里的值，就是那个多数元素。

### 3. 图解演示

假设数组为 `[2, 2, 1, 1, 1, 2, 2]`：

| 遍历到的元素 (`num`) | 当前候选人 (`candidate`) | 票数 (`count`) | 说明 |
| :---: | :---: | :---: | :--- |
| 初始状态 | 无 (None) | 0 | 初始状态 |
| **2** | **2** | 1 | `count`为0，**2**成为候选人，票数+1 |
| **2** | 2 | 2 | 遇到友军，票数+1 |
| **1** | 2 | 1 | 遇到敌军，同归于尽，票数-1 |
| **1** | 2 | 0 | 遇到敌军，同归于尽，票数-1。此时候选人阵亡 |
| **1** | **1** | 1 | `count`为0，**1**成为新候选人，票数+1 |
| **2** | 1 | 0 | 遇到敌军，同归于尽，票数-1。此时候选人阵亡 |
| **2** | **2** | 1 | `count`为0，**2**成为新候选人，票数+1 |

最终遍历结束，`candidate` 为 **2**，答案就是 2。

### 4. 代码实现
#### Python 3
```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        candidate = None
        count = 0
        
        for num in nums:
            if count == 0:
                candidate = num
            
            if num == candidate:
                count += 1
            else:
                count -= 1
                
        return candidate
```
