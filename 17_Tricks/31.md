LeetCode 第 31 题 **“下一个排列”（Next Permutation）** 是一道非常经典的算法题。它要求找出字典序中的下一个更大的排列；如果已经是最大排列（即整个数组降序），则将其重置为最小排列（即升序）。

这道题的难点在于：**如何在 $O(1)$ 的额外空间下，用 $O(N)$ 的时间找到“仅仅大一点点”的那一个排列？**

我们可以把数组里的数字想象成一个“大整数”。比如 `[1, 2, 3]` 就是 `123`，它的下一个排列是 `[1, 3, 2]`（132），再下一个是 `[2, 1, 3]`（213）。

下面我为你拆解这套绝妙的算法。

---

### 1. 核心直觉：如何让数字“变大”，且“变大的幅度最小”？

为了让数字变大，我们需要把**右边的一个大数**与**左边的一个小数**进行交换。
为了让变大的幅度**尽可能小**，我们需要遵循以下三个原则：
1. **尽量靠右交换**：也就是我们要找的那个“小数”必须尽量靠右（地位低，影响才小）。
2. **尽量找仅稍大一点的数交换**：跟那个“小数”交换的“大数”，必须是右边所有比它大的数中，**最小**的那一个。
3. **交换后，右边的数字要重置为最小状态**：也就是把右边的所有数字变成**升序**。

---

### 2. 标准的四步算法

根据以上直觉，前人总结出了一个完美的 $O(N)$ 算法。我们只需**从后往前**看这个数组。

**步骤 1：寻找尽量靠右的“小数”（寻找破坏降序的第一个元素）**
从后往前遍历，找到第一个出现**下降**趋势的数字。
设这个数字的索引为 `i`，即满足 `nums[i] < nums[i+1]`。
*此时，`nums[i+1]` 到末尾一定是一个**降序**序列，这就意味着这部分已经达到了它的最大字典序，没有变大的空间了。*

**步骤 2：在右侧降序区间中，寻找“刚好比它大一点的数”**
如果找到了这样的 `i`，我们再次从后往前遍历，在 `nums[i+1]` 到末尾这部分降序区间里，找到**第一个严格大于 `nums[i]`** 的数字。
设它的索引为 `j`，即满足 `nums[j] > nums[i]`。

**步骤 3：交换这两个数**
将 `nums[i]` 和 `nums[j]` 互换。
*因为 `nums[j]` 是刚出头的大数，换过去以后，前面的部分变大了。并且此时后面的区间**依然保持降序**。*

**步骤 4：将右侧区间反转（翻转降序为升序）**
现在，从 `i+1` 到末尾是一个降序排列，我们要让它变成字典序最小，也就是**升序**排列。
因为本来就是降序的，所以不需要调用 $O(N \log N)$ 的排序，**直接用双指针把这部分逆序（翻转）即可**。

> **边界情况：** 如果第一步没找到 `i`（比如数组是 `[3, 2, 1]`），说明整个数组都是降序的，已经是最大排列。我们直接跳过步骤2和3，直接执行步骤4（把整个数组翻转成升序 `[1, 2, 3]` 即可）。

### 3. 动画般的手工模拟（Dry Run）

用例子 `nums = [1, 3, 5, 4, 2]` 来推演一遍，我们要找它的下一个排列：

1. **从后往前找降序的转折点（找 `i`）：**
   - 看 2，再看 4（4 > 2）
   - 看 4，再看 5（5 > 4）
   - 看 5，再看 3（3 < 5） 👈 **找到了！**
   - 第一条下降的边发生在数字 `3`，所以小数是 `3`，索引 `i = 1`。
   - 此时右边的序列 `[5, 4, 2]` 是纯降序的。

2. **在右边 `[5, 4, 2]` 中从后往前找第一个大于 3 的数（找 `j`）：**
   - 遇到 2，不大于 3。
   - 遇到 4，大于 3。👈 **找到了！**
   - 所以大数是 `4`，索引 `j = 3`。

3. **交换 `nums[i]` 和 `nums[j]`：**
   - 将 `3` 和 `4` 交换。
   - 数组变成 `[1, 4, 5, 3, 2]`。
   - 注意：此时右边的序列 `[5, 3, 2]` 依然是纯降序的！

4. **反转右边的序列（索引 `i+1` 到末尾）：**
   - 将 `[5, 3, 2]` 反转变为 `[2, 3, 5]`。
   - 整体数组变为 `[1, 4, 2, 3, 5]`。

**最终结果就是：`[1, 4, 2, 3, 5]`**，这就是 `13542` 字典序里的下一个排列。

### 4. 代码实现 (Python & Java)

**Python 实现：**
```python
class Solution:
    def nextPermutation(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        n = len(nums)
        # 1. 从后往前寻找第一个下降的数字 nums[i]
        i = n - 2
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1
        
        # 如果找到了 i (说明不是全数组降序)
        if i >= 0:
            # 2. 从后往前找第一个比 nums[i] 大的数字 nums[j]
            j = n - 1
            while j >= 0 and nums[j] <= nums[i]:
                j -= 1
            # 3. 交换 i 和 j
            nums[i], nums[j] = nums[j], nums[i]
        
        # 4. 将 i 之后的序列反转 (如果是全降序，i=-1，这里就会反转整个数组)
        left, right = i + 1, n - 1
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1
```
