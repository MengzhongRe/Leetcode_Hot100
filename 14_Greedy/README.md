### 一、 暴力解法的痛点（为什么我们需要贪心？）

假设股票价格是 `prices =[7, 1, 5, 3, 6, 4]`。
**最本能的暴力法**：两层 `for` 循环。挑一天买入，再把后面所有的日子都看一遍，算出所有可能的利润，找最大值。
*   **痛点**：时间复杂度 $O(N^2)$。如果有 10 万天的数据，直接超时（Time Limit Exceeded）。

**破局思考**：我们真的需要往后看每一天吗？
如果我强制规定**“今天必须卖出”**，那我怎么才能赚得最多？
答案极其简单：**我只要知道在今天之前，哪一天的股票最便宜，然后在那天买入就行了！**

---

### 二、 贪心算法的核心心法：极致的“目光短浅”

所谓“贪心算法”，本质上就是**“只顾眼前的绝对局部最优，一步步推导出全局最优”**。

在这道题里，作为一个贪婪的炒股人，我每天只需要**贪婪地记住两件事**（维护两个变量）：
1.  **历史最低价 (`min_price`)**：只要今天比过去都便宜，我就贪婪地把它记作最低价，作为未来的潜在买入点。
2.  **历史最高利润 (`max_profit`)**：如果今天不买入，而是卖出，我就贪婪地算一下“今天的价格 - 历史最低价”。如果这个差价大于我之前赚过的钱，我就贪婪地更新我的最高利润！

#### 🎬 动画级推演：`[7, 1, 5, 3, 6, 4]`
*   **初始状态**：`min_price = 无穷大`，`max_profit = 0`。
*   **第 1 天 (7)**：太贵了，但没有历史对比，只能记下 `min_price = 7`。利润 = 0。
*   **第 2 天 (1)**：哇！1 块钱！比历史最低价 7 还便宜！贪心发作，更新 `min_price = 1`。利润依然 = 0（你总不能按 7 块买 1 块卖吧）。
*   **第 3 天 (5)**：没 1 块钱便宜。那如果今天卖呢？利润 = `5 - 1 = 4`。比之前的利润 0 大！贪心发作，更新 `max_profit = 4`。
*   **第 4 天 (3)**：没 1 块钱便宜。今天卖的话利润 = `3 - 1 = 2`。不如 4 赚得多，不管它。
*   **第 5 天 (6)**：没 1 块钱便宜。今天卖的话利润 = `6 - 1 = 5`。哇！赚了 5 块！贪心发作，更新 `max_profit = 5`。
*   **第 6 天 (4)**：没 1 块钱便宜。卖的话利润 `4 - 1 = 3`。不管它。

遍历结束！最高利润 `5`。我们**只遍历了一遍数组（$O(N)$）**，就找出了最高利润！

### 三、 极度优雅的核心代码 (Python)

贪心算法的代码往往短得令人发指，因为它没有任何复杂的数据结构（连栈和堆都不需要），只需要极其纯粹的逻辑比对。

利用 Python 内置的 `min()` 和 `max()` 函数，我们可以把代码写得极具数学美感：
```python
class Solution(object):
    def maxProfit(self, prices):
        min_price = float('inf')
        max_profit = 0
        
        for price in prices:
            # 每天都在贪婪地做两件事：
            min_price = min(min_price, price)                # 1. 刷新历史底价
            max_profit = max(max_profit, price - min_price)  # 2. 刷新最高利润
            
        return max_profit
```

---

### 四、 复杂度分析

*   **时间复杂度**：**$O(N)$**。就像开着一辆车从头到尾把数组扫了一遍，每个元素只看了一次，没有任何回头路。
*   **空间复杂度**：**$O(1)$**。只用了 `min_price` 和 `max_profit` 两个变量记录状态，没有开辟任何数组、栈或堆，极致省内存。

### 👑 架构师视角：贪心 vs 动态规划 (DP)

这道题其实是**动态规划（Dynamic Programming, DP）**的一维极简版！
如果你在这个时候能把这道题和 DP 联系起来，后面的硬核股票题你将如履平地。

在 DP 的视角下，状态转移方程是这样的：
`第 i 天的最大利润 = max(第 i-1 天的最大利润, 第 i 天卖出的利润)`

为了算出“第 i 天卖出的利润”，我们就必须知道“第 i 天之前的最低买入价”。
所以我们用一个变量 `min_price` 滚动记录历史最低价，用 `max_profit` 滚动记录最大利润。**我们用 $O(1)$ 的空间，完美压缩了 DP 本来需要 $O(N)$ 数组才能记录的状态！**

这就是贪心算法的魅力：**只要局部最优解（一直记录最低价）能够无条件地推导出全局最优解（最高利润），贪心就是成立的！**


贪心：每步局部最优，不回头，只做一次选择
DP：保存所有子问题结果，选择最优子结构组合
**贪心快但不一定正确；能用贪心的题，一般都是最优解法里最快的。DP 稳但相对慢**
